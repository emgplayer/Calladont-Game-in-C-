# Kaladont – Word Graph

A command-line implementation of the Kaladont word game developed in C as part of the Algorithms and Data Structures course at the School of Electrical Engineering, University of Belgrade.

## Features

* Graph representation using an adjacency matrix.
* Automatic construction of graph edges based on word connections.
* An edge exists between two words when the last two characters of the first word match the first two characters of the second word.
* Graph traversal to determine the number of distinct reachable words.
* Shortest path analysis using the Floyd–Warshall algorithm.
* Calculation of graph properties, including reachability, efficiency, and distance to terminal vertices.
* Handling of cycles and terminal vertices.

## Technologies and Algorithms

* C
* Graphs and adjacency matrices
* Graph traversal
* Floyd–Warshall algorithm
* Shortest path algorithms
* Reachability analysis

## Purpose

The project focuses on applying graph theory and graph algorithms to a word-based problem. It demonstrates graph modeling, path analysis, cycle handling, and the calculation of graph metrics using fundamental algorithms and data structures.
